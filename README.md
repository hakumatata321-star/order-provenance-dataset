# Order Provenance Dataset

Why each purchase order was placed in multi-supplier stockrooms: 1,500 synthetic stockrooms, 13,303 items,
662,650 purchase orders over 700 days, with periodic stock counts and weekly sales.

Every order carries a hidden cause: a scheduled periodic review, the item's own reorder point, or being swept
into a purchase order that was opened for another item of the same supplier. When an order was swept in, the
label names the specific earlier order whose purchase order it joined, so the labels form a provenance graph
over the order book.

- **Origin:** fully synthetic, generated by the creator. Every draw and identifier is derived from HMAC-SHA256
  keyed to a withheld secret; the generator code and the secret are not published. No real operational records,
  no personal data and no third-party material.
- **Files:** `stockrooms.csv`, `items.csv`, `orders.csv`, `stock_counts.csv`, `weekly_sales.csv`, `provenance.csv`,
  plus `source_metadata.json`, `DATASET_CARD.md`, `DATASET_DESCRIPTION.md`, `ATTRIBUTION.txt` and `LICENSE`.
- **Full documentation:** [DATASET_DESCRIPTION.md](DATASET_DESCRIPTION.md).
- **Intended use:** research and benchmarking of event-level cause attribution and structure recovery from
  sparse, noisy operational logs.
- **Out of scope:** any claim about real purchasing operations, suppliers or products.
